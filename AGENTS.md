# Repository scope

This is public methodology and runnable development code for tower-defense Task v2.0.1.
Keep one current version in the main view. Preserve previous material in archive refs.
Do not import company internals, raw private reports, conversations, account data or credentials.
Game-source provenance is restricted to approved Codex/Claude materials. Record tool and model separately.
Verify core source hashes and publication-manifest.json before publication. Distinguish measured results from acceptance.
The current source and public development protocol are in tower-defense/; the official Harbor Task and complete
experiment records live in the Foundation's private current review package.
