# Repository purpose

This public repository contains methodology, a runnable task and selected publication materials for OpenRSI task creation and review. Keep changes within that purpose unless the user expands the scope.

- Read README.md and docs/task-preparation.md before changing task scope.
- Use this repository and public sources. Read other local projects only when the user explicitly authorizes it.
- Only the explicitly approved game-only public preview files and selected Codex/Claude Code publication report extracts may be imported from the reference project. Do not copy other private project files, raw runs, conversations, account data, credentials, internal services or production details into this repository.
- Game creation scope is limited to Codex and Claude. Record the actual tool, model and version separately; do not equate a tool name with a model identity.
- Distinguish proposed choices, implemented interfaces, measured results and approval status. Do not invent completed baselines, assets, scores or runtime measurements.
- A report schema validates structure only. Evidence linkage and semantic correctness require independent checks.
- No game generation, paid model calls, deployment or external messages are implied by documentation work.
- Check git status before editing and preserve unrelated changes. Review the diff for public suitability before publication.
- The runnable contract is docs/evaluation-contract.md. After task-source changes, run scripts/package_environment.py to refresh the deterministic environment bundle and Judge-only evaluator copies. Keep root and environment requirements.txt identical.

An OpenRSI proposal session whose complete original history will be uploaded must contain only materials approved for that workflow. Do not upload a session that has read private material, and do not filter a native session to make it appear safe.
